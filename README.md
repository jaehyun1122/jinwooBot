# jinwooBot

카카오톡 오픈채팅 관리/알림 보조 봇입니다. `DBManager_deploy` 리스너를 통해 채팅 이벤트를 수집/처리하고, 입퇴장 감지, 멤버별 코드 관리, 멘션/답장 알림, 삭제 메시지 기록, 재입장 메모, 잠수자 목록 등의 기능을 제공합니다.

## 주요 기능

- 입퇴장/초대/강퇴 감지 및 안내 메시지 전송
- 멤버별 6자리 대문자 코드 부여 및 1회 변경 지원
- 멘션/답장 알림 큐 관리(.알림켜기/.알림끄기로 제어)
- 메시지 인용 응답(밑메), 읽은 사람 확인, 방 목록 출력
- 최근 삭제된 메시지 기록 조회(방별 최대 10개 저장)
- 재입장 메모 기능(입퇴감지 메시지에 답장 후 .메모로 메모 저장/표시)
- 7일 이상 미채팅(잠수) 사용자 목록 조회
- 관리자 전용: JS 평가 실행, 특정 방에 코드로 메시지 전송

## 실행 환경 및 의존성

- DB 리스너: `DBManager_deploy-2/modules/DBManager`
- 전역 객체: `FileStream`, `Api`, `java.text.SimpleDateFormat`(호스트 런타임 제공)
- 저장소 경로(안드로이드): `/sdcard/DB/*.txt`

런타임은 안드로이드 파일 접근 권한이 필요하며, 위 전역 객체들이 제공되는 봇 플랫폼(예: NyangBot 기반)에서 동작하도록 작성되어 있습니다.

## 설정

`index.js` 상단에서 다음 값을 프로젝트에 맞게 수정하세요.

- `prefix`: 명령어 접두사(기본값: `.`)
- `Admin_Room`: 관리자 알림/중계 방 이름 또는 ID
- `defaultNotiOn`: 개인 알림 기본값(true/false)
- `admin`: 관리자 사용자 ID 목록(배열)

## 데이터 파일(자동 생성)

다음 파일들은 `/sdcard/DB` 하위에 생성/유지됩니다.

- `enter.txt`: 방별 입장/퇴장/강퇴 이력 및 설정(on/off)
- `del.txt`: 방별 최근 삭제 메시지 이력(최대 10개)
- `memo.txt`: 방별 코드에 매핑된 메모 저장소
- `jamsu.txt`: 방별 사용자 마지막 발언 타임스탬프(잠수 계산)
- `codes.txt`: 방/사용자별 부여된 6자리 코드와 변경 이력
- `notis.txt`: 사용자별 멘션/답장 알림 큐 및 on/off 상태
- `cmd.txt`: `.명령어` 호출 시 출력되는 커맨드 안내 텍스트

파일이 없으면 최초 실행 시 자동 생성됩니다.

## 사용 방법(명령어)

접두사 `prefix` 기본값은 `.` 입니다. 아래 예시는 `.` 기준입니다.

- `.명령어` 또는 `.도움말`: 명령어 안내(`cmd.txt` 내용 출력)
- `.알림켜기` / `.알림끄기`: 내 멘션/답장 알림 on/off
- `.__아이디`: 내 ID 확인(답장 상태라면 그 사용자의 ID 출력)
- `.코드`: 내 6자리 코드 조회(답장 상태라면 해당 사용자의 코드 조회)
- `.코드 ABCDEF`: 내 코드를 1회에 한해 변경(대문자 6자리, 중복 불가)
- `.방목록`: 봇이 알고 있는 방 이름/코드 목록 출력(방장/부방장 전용)
- `.밑메 [N]`: 답장 기준으로 아래쪽 N번째 메시지 인용 출력(기본 1, 최대 10)
- `.삭제`: 최근 삭제된 메시지 목록 출력
- `.읽은사람`: 답장한 메시지의 읽은 사람 목록 출력(방장/부방장 전용)
- `.퇴감지 켜기|끄기`: 방 입퇴장 감지 알림 on/off(방장 전용)
- `.퇴감지 초기화`: 방 입퇴장 기록 초기화(방장 전용, 10초 내 재확인 필요)
- `.메모 내용`: 입퇴감지 메시지에 답장한 상태에서 해당 사용자 코드에 메모 저장
- `.잠수`: 7일 이상 대화가 없는 사용자 목록 출력
- 관리자 전용
  - `d <javascript>`: JS 평가 결과 전송
  - 특정 방으로 메시지 전송: 방 코드와 함께 전송하는 관리자 명령(코드 참조)

주의: 방장/부방장 전용 명령은 `memberType` 권한 체크를 통과해야 합니다.

## 동작 개요(이벤트)

- `message`: 채팅 메시지 처리, 명령어 라우팅, 알림 큐 적재/배달
- `join`/`invite`: 입장/초대 감지, 코드 생성, 안내 메시지 및 기록 저장
- `leave`/`kick`: 퇴장/강퇴 감지, 안내 메시지 및 기록 저장(강퇴 시 가해자 포함)
- `delete`: 삭제 메시지 수집 및 최근 10개 유지
- `member_type_change`: 승격/강등/방장 변경 안내

## 팁

- `.명령어` 출력 형식을 바꾸고 싶다면 `cmd.txt`를 수정하세요.
- 방 코드와 사용자 코드는 `codes.txt`에서 관리됩니다. 이름 변경/방 이동 시 자동 반영됩니다.
- 알림이 너무 많다면 `.알림끄기`로 개인별로 비활성화할 수 있습니다.
